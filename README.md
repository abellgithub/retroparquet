# retroparquet

A repository for documenting the Retroparquet file format specification.

## Overview

Retroparquet is a file format specification designed for efficient columnar data storage. This repository contains the complete specification and documentation.

## Contents

- [Format Specification](spec/format-spec.md) - The complete Retroparquet file format specification

## Purpose

This repository serves as the authoritative source for the Retroparquet file format documentation, providing developers with the information needed to implement readers, writers, and tools for Retroparquet files.
